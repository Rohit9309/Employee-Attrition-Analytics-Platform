# Employee Attrition Analytics Platform

End-to-end educational HR analytics project using the supplied HR Attrition Indian Dataset.

## Features
- Classical ML comparison: Logistic Regression, Decision Tree, Random Forest, XGBoost
- Advanced models: MLP neural network, Gaussian Naive Bayes, Linear Discriminant Analysis (where valid)
- Evaluation: accuracy, precision, recall, F1, ROC-AUC, confusion matrix, ROC curve, stratified cross-validation
- HR analytics dashboard: attrition and retention KPIs, department trends, workforce demographics, risk categories, model metrics
- FastAPI prediction endpoint and OpenAPI docs
- IBM Watson Studio / Watson Machine Learning deployment guide and scheduled retraining workflow outline
- Technical report and executive presentation starter

## Dataset
- File: `data/HR_Attrition_Indian_Dataset.csv`
- Target: `LeftCompany` (`Yes` means left; `No` means stayed)
- Records: 5,000
- Columns: 22

## Quick start (Windows)
Open Git Bash or a terminal in this folder:

```bash
python -m venv .venv
# PowerShell:
.venv\Scripts\Activate.ps1
# Git Bash:
source .venv/Scripts/activate
pip install -r requirements.txt
python train_models.py
```

Then start the dashboard:
```bash
streamlit run app/dashboard.py
```

Start the REST API after training:
```bash
uvicorn api.main:app --reload
```
Open `http://127.0.0.1:8000/docs` for interactive API documentation.

## Notebook
Open `notebooks/advanced_model_comparison.ipynb` in Jupyter and run cells from top to bottom.

This is a learning prototype, not a validated employment decision system. Do not use predictions to automate hiring, firing, promotion, compensation or other consequential employment decisions. Predictions are not causal explanations. Before any real-world use, review privacy, data quality, fairness, explainability, legal requirements and human oversight. The included sample data may be synthetic or not representative of a real workforce.
